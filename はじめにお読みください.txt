数学教材ジェネレーター
「はじめにお読みください」
==================================================

ご購入ありがとうございます。
このアプリは、パソコンの中で小さなサーバーを動かして、
ブラウザで使う仕組みになっています。
使い方は簡単です。下の順番で進めてください。

--------------------------------------------------

--------------------------------------------------

① ZIPファイルを展開（解凍）する
ダウンロードした ZIP ファイルを右クリックして
「すべて展開」を選び、好きな場所に展開してください。
※ 展開せずに ZIP の中から直接起動すると動きません。

② start.bat をダブルクリックする
展開したフォルダの中にある「start.bat」を
ダブルクリックしてください。

③ 黒い画面はアプリ本体です。閉じないでください
黒い画面が開きますが、これはアプリ本体です。
使い終わるまで閉じないでください。
閉じてしまうと、アプリも終了します。

④ ブラウザが自動で開きます
少し待つと、ブラウザが自動で開いて、
アプリの画面が表示されます。
※ 初回だけ、部品の準備に数分かかることがあります。
※ ブラウザが自動で開かない場合は、ブラウザの
アドレス欄に次のアドレスを入力してください。
http://127.0.0.1:5000

⑤ 赤い文字が出ても正常です
起動の途中で、英語の赤い文字の注意書きが
出ることがありますが、これは正常な表示です。
心配いりません。そのままお使いください。

⑥ 終わるときは、黒い画面を閉じる
使い終わったら、黒い画面を閉じてください。
（キーボードの Ctrl + C でも終了できます）

--------------------------------------------------

--------------------------------------------------

・「Python が見つかりませんでした」と表示された
→ このアプリには Python が必要です。
公式サイト https://www.python.org/ から
Python をインストールしてください。
インストールのときは「Add python.exe to PATH」に
チェックを入れるのがおすすめです。
そのあと、もう一度 start.bat をダブルクリック
してください。

・「準備に失敗しました」と表示された
→ インターネット接続を確認してから、もう一度
start.bat をダブルクリックしてみてください。

・ブラウザに画面が出ない
→ 黒い画面が開いたままになっているか確認して、
ブラウザで http://127.0.0.1:5000 を
開き直してみてください。

・詳しい操作手順は、フォルダ内の MANUAL.md を
ご覧ください。
